# Mode Manusia Penuh (autonomy.js)

Aktif lewat `settings.json` -> `"autonomy": { "enabled": true }`. Mati: set `enabled` ke `false` (bot kembali ke perilaku lama).

Perintah konsol panel: `/auto on|off`, `/build [ukuran]`, `/collect <item> [n]`, `/craft <item> [n]`, `/kill <pemain|mob>`, `/pillar [n]`, `/cancel`, `/autostatus`.
Perintah in-game (hanya pemain di `owners`): `!build`, `!collect`, `!craft`, `!kill`, `!come`, `!cancel`, `!status`.

Opsi: `combat.players` = `defend` (membalas yang menyerang) | `never` | `all`; `build.material` = `auto|cobblestone|planks|dirt`; `progress.max-tier` = `stone|iron|diamond`.
